Terms of Use

Last updated 16 November 2026. Wave Uninstaller is MIT-licensed free software. This restates what that means for someone running it.

Wave modifies your system. It removes registry keys and moves files out of the places programs install into. On the wrong entry that breaks other software. Wave's backup makes every operation reversible, but a backup you never test is a plan, not a guarantee — keep an independent one.

No warranty

Provided “as is”. The authors are not liable for lost data, broken installations or any other damage. Not boilerplate: a program that deletes files and edits the registry can do real harm if it gets something wrong, and running it is your decision.

What Wave sends

Nothing. No telemetry, no analytics, no crash reporting, no account, no network requests of its own. A program with system privileges that phones home does not deserve trust.

What this site does with your visit is under Privacy below.

What it reads

The registry, the MSI product database, the installed Store packages, and the folders programs keep their files in: Program Files, ProgramData, AppData and the start menu. All of it stays on the machine.

What it writes

What you approve, and only into a backup: files and folders are moved to %ProgramData%\Wave\Backups rather than deleted, registry keys are exported there as JSON and as a .reg file before they are removed, and every step is written to a journal before it runs. The Backups window puts an operation back. A program whose own uninstaller has run is the exception — that has to be installed again.

Administrator rights

Wave asks for them when it starts. Removing a machine-wide program means writing to HKEY_LOCAL_MACHINE and to Program Files, and being refused halfway through a removal is worse than being asked once at the beginning.

Third-party software

Wave starts the uninstaller a program shipped with itself. What that uninstaller does is its author's responsibility.

Privacy

Who is responsible

Wave Uninstaller and this site are run by Sebi. For anything about your data, message @aquaxs on Telegram.

The program

Everything Wave reads and writes stays on your machine. None of it is sent anywhere, and Sebi never receives any of it. The backups and journals in %ProgramData%\Wave\Backups record each removal and can contain files of the removed program, including what it kept in your user profile. Wave never deletes them on its own: they stay until you delete the folder. Wave has no account and writes no log file.
