Terms of Use

Last updated 7 September 2026. Wave Uninstaller is MIT-licensed free software. This restates what that means for someone running it.

Wave modifies your system. Once past the current read-only state it will remove registry keys, delete files and unregister services. On the wrong entry that breaks other software. Wave's backup makes every operation reversible, but a backup you never test is a plan, not a guarantee — keep an independent one.

No warranty

Provided “as is”. The authors are not liable for lost data, broken installations or any other damage. Not boilerplate: a program that deletes files and edits the registry can do real harm if it gets something wrong, and running it is your decision.

What Wave sends

Nothing. No telemetry, no analytics, no crash reporting, no account, no network requests of its own. A program with system privileges that phones home does not deserve trust.

This site is equally quiet: no cookies, no analytics, no third-party requests. Your theme choice stays in your browser.

What it reads

The registry, the MSI product database and the installed Store packages. Later phases will also walk parts of the file system. All of it stays on the machine.

Administrator rights

Reading the inventory needs none. Removing machine-wide programs will, and Wave asks at that point rather than up front.

Third-party software

Wave starts the uninstaller a program shipped with itself. What that uninstaller does is its author's responsibility.

Changes

These terms change as the software gains the ability to do more. The current version is this page; the history is in the repository.
