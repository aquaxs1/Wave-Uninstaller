Windows 10 (1809+) and 11, 64-bit. Free, MIT licensed, no account, no telemetry.

This build removes things. It runs a program's uninstaller and then moves the leftovers it finds — folders, registry keys, startup entries — into a backup under %ProgramData%\Wave\Backups. Nothing is deleted, every step is journalled before it runs, and every removal can be put back from the Backups window. It asks for administrator rights on start, because removing a machine-wide program needs them. It is early software: read what it proposes before you approve it.

SmartScreen will warn you

The builds are not code-signed, so Windows shows “protected your PC” on first launch. Choose More info, then Run anyway. A signing certificate is P5 on the roadmap; until then the warning is expected and this page would rather say so than let you wonder.

Verify the file

Every release ships SHA256SUMS.txt, covering the zip too. In PowerShell: 

Get-FileHash .\Wave-Uninstaller-Portable-x64.zip -Algorithm SHA256

Compare the result with the line for that file in the checksum list.

Build it yourself

Everything the release workflow does is in the repository. With Rust and Node installed: 

git clone https://github.com/aquaxs1/Wave-uninstaller
cd Wave-uninstaller
npm install
npm run tauri build
